# Contributing

## Before the first commit

```
sh tools/install-hooks.sh
git config user.email YOUR-ID+YOUR-NAME@users.noreply.github.com
```

In GitHub, Settings, Emails: turn on "Keep my email addresses private" and "Block command line pushes that expose my email".

The hooks run `tools/check-repo.py`. It refuses personal e-mail addresses, absolute paths with a real user name, secrets, binary files that are not listed in `tools/repo-allowlist.txt`, and files over 1 MB. Put names that must never appear, one per line, in `tools/.private-terms` (this file is ignored by git).

## What does not belong in the repository

* Screenshots or recordings of a real screen: they show other people's products, personal names and avatars. Use images generated by `prototype/tests/gen.js`, or keep real captures outside the repository (the `private/` folder is ignored).
* Models, programs or text that belong to others. A plugin refers to them and the user obtains them from their owners; the plugin names them under `credits`, spelled as the owner spells them.
* Anything whose license is unclear or carries limits on region, audience size or brand use.

See `docs/design.md` sections 30.17, 30.19 and 30.21.

## Tests (guard only)

```

python3 tools/test-check-repo.py
```
